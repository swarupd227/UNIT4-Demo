# 1. Getting started

Last updated: May 2024

Project Billing turns approved time and expenses into customer invoices. You work in your web browser. There is nothing to install.

## The top bar

Every page has the same bar across the top. It shows:

- **Kestrel Consulting Project Billing**, the name of the module.
- **Business date**, the date Project Billing works to. This is not always today's date. See [The business date and the billing period](02-business-date-and-billing-period.md).
- **User**, a list with your name and your role, for example *Anna Virtanen (Billing clerk)*.

Check that your own name is selected in the **User** list before you start. If it is not, select it. The page reloads and stays where you were. Project Billing records your name:

- in the **Created by** column when you create a proposal,
- in the **Finalised** line when you finalise an invoice or issue a credit note.

The version number is shown at the bottom of every page, for example *Project Billing 4.8.2 · Kestrel Consulting Oy*. Quote it if you contact the finance systems team.

## The home page

Select **Home** in the menu to open the home page. It shows:

- **Billing period ending**, the last day of the month of the business date. This is the period end that new proposals use by default.
- Tiles with counts. Select a tile to go to the related page.
  - **Open proposals**: proposals that have been created but not yet finalised.
  - **Projects with unbilled time**: projects with approved, billable time that has not been billed or added to a proposal, dated on or before the period end.
  - **Invoices this month**: final invoices with an invoice date in the month of the business date. Credit notes are not counted.
- **Billing holds**: every customer and project that is on billing hold, with the reason. If there are none, the page says "No customers or projects are on hold."

## A typical month

1. Check the **Billing holds** list on the home page.
2. Check that the exchange rates for the month have been entered. See [Currencies and exchange rates](17-currencies-and-exchange-rates.md).
3. Create a proposal for each project with something to bill. See [Creating a proposal](13-creating-a-proposal.md).
4. Check each proposal with the project manager. Write lines up or down where needed, and add purchase order numbers.
5. Finalise the proposals. Each one becomes a numbered invoice.
6. Export the invoice list for the month if your team needs it.

## Messages

When something works, a short confirmation appears in a box at the top of the page, for example "Proposal deleted." When something cannot be done, a message explains why. The messages are listed in [Troubleshooting](27-troubleshooting.md).

If you see the page "Something went wrong", the request could not be completed. Try again once. If it happens again, contact the finance systems team and tell them what you were doing.
