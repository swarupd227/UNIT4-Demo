# 3. The menu

Last updated: May 2024

The menu runs across every page, below the top bar. This page describes each item.

## Home

The start page. It shows the billing period, counts of open work and the list of billing holds. See [Getting started](01-getting-started.md).

## Customers

A list of all customers with their **Code**, **Name**, **Currency**, **Country**, **Payment terms**, **Discount**, **PO required** and **Status**. Select a customer code to open the customer and change its billing settings. See [Customers](04-customers.md).

## Projects

A list of all projects with their **Code**, **Name**, **Customer**, **Billing** type, **Status** and **Unbilled hours**. Use **Search** to find a project by code, project name or customer name. Select a project code to open the project page, where you can see unbilled time and expenses, set a billing hold, mark milestones complete and create a proposal. See [Projects](06-projects.md).

## Proposals

The heading on this page is **Invoice proposals**. It lists every proposal that has not been finalised, newest first, with these columns:

- **Proposal**, the proposal reference, for example P00012. Select it to open the proposal.
- **Project** and **Customer**.
- **Period end**.
- **Status**, for example *Proposal* or *Deferred*.
- **Total**, including tax, in the invoice currency.
- **Created by**.

Select **New proposal** to create one. If there are none, the page says "No open proposals."

## Invoices

The heading on this page is **Invoices and credit notes**. It lists final invoices and credit notes. You can search, filter by type and export. See [The invoice list and export](26-invoice-list-and-export.md).

## Exchange rates

The rates from EUR to each customer currency, with the date each rate is effective from. Billing managers enter new rates here. See [Currencies and exchange rates](17-currencies-and-exchange-rates.md).

## Tax codes

A read-only list of the tax codes, with their description, rate and whether they are exempt. See [VAT and tax codes](15-vat-and-tax-codes.md).

## Moving around

- Links in tables (customer codes, project codes, proposal references and invoice numbers) open the record.
- On a customer page, **Back** returns to the customer list.
- On the new proposal page, **Cancel** returns to the proposal list without creating anything.
- On the credit note page, **Cancel** returns to the invoice without issuing anything.
